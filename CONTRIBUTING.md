# 🤝 Contributing – Nightingale Demos Portal

Please follow these instructions when contributing to this repository:

## 🔄 Updating Demos

- Edit `DEMOS_OVERVIEW.md`:
  - Add a new row for each new demo
  - Follow naming conventions (`nightingale-[demo-name]`)
- Update contacts and current status as needed

## 📝 Naming Convention

Each demo repository should be named depending on the server (domain):
```
nightingale-[demo-name]
healthview-[demo-name]
healthmap-[demo-name]
other-[demo-name]
```

Example: `nightingale-pollutionmap`

## 📦 Do NOT include any code here
This repository is documentation-only and must remain clean of application code.
